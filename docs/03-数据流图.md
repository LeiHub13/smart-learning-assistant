# 系统数据流图

## 1. 登录认证

```
前端 LoginView ──POST /api/auth/login {username,password}──> AuthService
    AuthService: 查 t_user(密码加盐哈希比对) → JwtTokenService 签发
    <── {accessToken(2h), refreshToken(7d)} ──
    前端 localStorage 存 token → 后续请求头 Authorization: Bearer xxx
    AuthInterceptor(security/AuthInterceptor) 拦截校验 → CurrentUser 注入 controller
```

## 2. 知识库文档索引（数据入口）

```
教师 ManageView ──POST /api/kb/{kbId}/documents {name,content}──> KbController
    └─> KbService.indexTextDocument
        ├─ 建 t_document 记录(parse_status=SUCCESS)
        ├─ 文本按 200 字符切块 → t_chunk(doc_id,kb_id,idx,content)    ← chunk 落库
        ├─ 每块哈希嵌入(HashEmbeddingService 128维) → InMemoryVectorStore.put(chunkId,vec)
        └─ 更新 t_document.chunk_count
文件上传: MultipartFile → LocalFileStorage(./data/files) → t_document(PENDING)
    → MessagePublisher 发 kb.document.index 任务 → 消费者索引(同链路)
重启: DataSeeder → reindexFromChunks() 读 t_chunk 全量重建内存向量库
```

## 3. AI 答疑（RAG + 会话，核心链路）

```
前端 ChatView
  │ POST /api/chat/sessions/{id}/stream {message}
  ▼
ChatController(SseEmitter)
  ▼
ChatService.streamMessage
  ├─① t_chat_message 存用户消息(role=user)
  ├─② 检索: 问题 → HashEmbeddingService.embed → InMemoryVectorStore.search(Top5)
  │     → t_chunk 取内容 → 拼 "[1]内容 [2]内容..."（无命中→"暂无相关资料"）
  ├─③ 组装 system = "RAG_QA\n…【知识库资料】[1]..【资料结束】\nSESSION_ID:{会话id}"
  │     history = 最近 10 轮 t_chat_message(role/content)
  ├─④ ChatModelFactory.get() → PythonAIChatModel
  │     POST http://localhost:8000/ai/stream {scene:rag_qa, question, chunks, sessionId}
  │       ▼
  │     ai-service: memory.py 读 data/memory/{sessionId}.jsonl(近5轮)
  │       → chains.py rag_qa 链(系统提示+资料+记忆) → ChatOpenAI(DeepSeek)
  │       → 流式 delta → SSE data:{"delta":"字"}…
  │       → {"done":true}
  │   PythonAIChatModel 独立线程逐块读 → onDelta 回调 → SseEmitter.send
  │     完成回调 → ai-service memory.py 追加本轮问答到 jsonl
  ├─⑤ 完成后: t_chat_message 存 assistant(含 sources="1,2,3")
  │           t_llm_call_log 记调用(模型/耗时)
  ▼
前端 ReadableStream 逐字渲染 + "引用来源：知识库片段 1、2、3"
```

## 4. 讲义 / 题目生成

```
GenerateView ──POST /api/generate/lecture {courseId,topic,kp}──> GeneratorService
    system="GEN_LECTURE" → Python /ai/complete {scene:lecture} → {content(Markdown)}
    → t_generated_content(type=lecture) 落库 → 前端渲染

GenerateView ──POST /api/generate/questions {courseId,kp,count}──> GeneratorService
    system="GEN_QUESTIONS" → Python /ai/complete {scene:questions}
    → 返回 JSON 数组 → Jackson 解析 → 逐题插入 t_question(source=ai)
    → 返回题目列表(含答案/解析) → 前端展示
```

## 5. 练习 → 批改 → 掌握度

```
PracticeView
  ├─GET /api/practice/paper?courseId&count → PracticeService.paper
  │    按课程从 t_question 随机抽题(隐藏 answer/analysis)
  ├─POST /api/practice/submit {courseId, items:[{questionId,answer}]}
  │    PracticeService.submit 逐题:
  │      客观题(单选/判断/多选): 规则判分(忽略大小写/剔非字母排序比较)
  │      问答题: system="REVIEW_SUBJECTIVE" → Python /ai/complete {scene:review}
  │              → {"score":0-10,"comment"} → 解析
  │      → t_practice 汇总分 + t_practice_question(score,correct,review,kpName)
  │      → 按知识点聚合 attempts/correct → 更新 t_knowledge_mastery(mastery加权)
  └─GET /api/practice/{id} → 报告(题目+参考答案+AI点评+得分)
```

## 6. 学情汇总 → AI 建议

```
ProgressView ──GET /api/progress/summary?courseId──> ProgressService
    ├─t_knowledge_mastery 按知识点聚合 → masteries[]
    ├─错题统计(练习记录) → 薄弱知识点
    └─system="ADVICE" + 掌握度数据 → Python /ai/complete {scene:advice}
         → 分条复习建议(真实模型生成) → 前端展示
```

│        t_chunk t_question t_practice t_practice_question               │

```

## 8. 一句话总结

```
文档/题目/会话数据都落 H2；向量在 Java 内存；文本与向量只在 Java 内部流动；
Java 只把"问题 + 检索到的资料 + 会话ID"发给 Python；Python 只调模型并回传文本；
前端只管渲染 SSE 增量 —— 数据不经过第三个存储，模型不见库。
